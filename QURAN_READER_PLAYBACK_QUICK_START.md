# Quran Reader Playback - Quick Start Guide

## 🚀 How to Use the New Feature

### Step 1: Find the Play Button
Look for the **golden play button** below the gear icon on the right side of the screen (translation view only).

```
┌─────────────────────────────┐
│                         ⚙️  │  ← Gear Icon (Settings)
│  Quran Reader              │
│                         ▶️  │  ← NEW Play Button
│                             │
│  Surah Al-Fatihah          │
│  Verse 1...                │
└─────────────────────────────┘
```

### Step 2: Choose Your Playback Mode

Click the play button to open the **Playback Options** dialog:

```
┌──────────────────────────────────────┐
│  ▶️  Playback Options             ✕  │
├──────────────────────────────────────┤
│  Current Surah: Al-Fatihah (7 verses)│
│                                       │
│  ┌──────────────────────────────────┐│
│  │ ⏮  Play from Beginning          ││ ← Start from verse 1
│  │    Start from verse 1...         ││
│  └──────────────────────────────────┘│
│                                       │
│  ┌──────────────────────────────────┐│
│  │ ▶️  Play from Current Verse      ││ ← Auto-detect position
│  │    From verse 3                  ││
│  └──────────────────────────────────┘│
│                                       │
│  ┌──────────────────────────────────┐│
│  │ 🎛️  Custom Range                 ││
│  │    From: [1 ▼]  →  To: [7 ▼]    ││ ← Choose specific verses
│  │    [▶️ Play Range]               ││
│  └──────────────────────────────────┘│
│                                       │
│  ┌──────────────────────────────────┐│
│  │ 🎵  Play Full Surah (Background) ││ ← Continuous audio
│  │    Continuous audio without...   ││
│  └──────────────────────────────────┘│
└──────────────────────────────────────┘
```

### Step 3: Enjoy the Playback

Once you select a mode, the **minimized player** appears at the bottom:

```
┌─────────────────────────────────────────────────────────┐
│  📻 Surah Al-Fatihah - Verse 3   [▬▬▬▬▬▬▬▬▬░░] 3/7   ⏸ ⏹ │
└─────────────────────────────────────────────────────────┘
    ↑                                ↑            ↑  ↑
   Playing                       Progress    Pause Stop
```

### Features You'll Notice

#### 1. **Auto-Scroll** 🎯
The page automatically scrolls to keep the current verse visible.

#### 2. **Blue Highlight** 💙
The currently playing verse has a blue pulsing border:

```
┌──────────────────────────────────────┐
│  Verse 1: Bismillah...              │
│  Verse 2: Alhamdulillah...          │
│ ┌───────────────────────────────────┤
│ │🔵 Verse 3: Ar-Rahman...  ← Playing │
│ └───────────────────────────────────┤
│  Verse 4: Malik...                  │
└──────────────────────────────────────┘
```

#### 3. **Progress Tracking** 📊
- Verse counter: "Verse 3 of 7"
- Progress bar (desktop)
- Current surah name

#### 4. **Playback Controls** 🎮
- **⏸ Pause**: Pause current verse
- **▶️ Resume**: Continue from where you paused
- **⏹ Stop**: Stop playback and close player

## 🎯 Quick Tips

### Tip 1: Current Verse Detection
Click any verse before opening the play dialog to set it as the "current verse" for "Play from Current" mode.

### Tip 2: Custom Range for Practice
Use Custom Range to repeat specific verses you're memorizing:
- From: 5 → To: 7
- Perfect for focused practice!

### Tip 3: Background Mode
Use "Play Full Surah (Background)" for:
- ✅ Continuous listening (no pauses)
- ✅ While reading along at your own pace
- ✅ Background recitation

### Tip 4: Keyboard-Friendly
- Click anywhere outside the dialog to close it
- All buttons have hover tooltips for guidance

## 🔧 Troubleshooting

### "I don't see the play button"
- Make sure you're in **Translation View** (not Mushaf view)
- Minimize the controls by clicking the gear icon
- The button is hidden in assignment mode

### "It's not starting from where I am"
- Click the verse you want to start from
- Then open the play dialog
- Or use **Custom Range** for precise control

### "Audio is slow to start"
- This is normal (loading audio from server)
- Each verse loads individually
- Check your internet connection
