🔧 Set User Role

Development helper to set custom role claims

⚠️ Development Only: This tool is for testing purposes. In production, use proper admin authentication.
Find this in Firebase Console → Authentication → Users
📝 Instructions:
  1. Deploy functions: cd functions && npm run deploy
  2. Get user UID from Firebase Console
  3. Select role and click "Set Role"
  4. User must sign out and sign in again for changes to take effect
